# Latent Gradient Steering: Usage Guide

This guide provides a comprehensive overview of the **Latent Gradient Steering (LGS)** system, including details about the underlying methodology, script inputs, expected outputs, unit testing, and execution instructions.

---

## 1. Introduction & Architecture

Traditional autoregressive sequence modeling generates text token-by-token based on default probability distributions learned during pre-training. While techniques like Chain-of-Thought (CoT) and post-hoc verification prune or structure outputs, they remain constrained by the model's base token-prediction priors.

**Latent Gradient Steering (LGS)** bridges continuous representation space with discrete token prediction by actively steering the model's internal hidden states ($h_t$) *before* they are projected through the Language Model (LM) Head.

### Mathematical Objective Function

At each generation step, the initial hidden state $h_{\text{initial}}$ is optimized using the Adam optimizer to maximize the continuous objective function:

$$\mathcal{J}(h_t) = \cos(h_t, \mathbf{c}_{\text{ideal}}) - 0.5 \cdot \cos(h_t, \mathbf{c}_{\text{corrupt}}) - \lambda \Vert h_t - h_{\text{initial}} \Vert_2$$

Where:
* $\cos(h_t, \mathbf{c}_{\text{ideal}})$: Pulls the generation toward the structural representation of positive/ideal exemplars.
* $- 0.5 \cdot \cos(h_t, \mathbf{c}_{\text{corrupt}})$: Repels the generation from negative/corrupt exemplars (such as logical fallacies, ungrounded hand-waving, or inappropriate tone).
* $\lambda \Vert h_t - h_{\text{initial}} \Vert_2$: L2 regularization that preserves grammatical integrity by preventing the hidden state from drifting too far from the model's coherent thinking manifold.

* **`latent_gradient_steering.ipynb`**: Interactive Jupyter/Google Colab notebook with an A/B double-blind experiment comparing Control and Treatment generation.

## 3. Inputs & Parameters

The functions within `latent_gradient_steering.py` accept the following key inputs and hyper-parameters:

### Core Inputs
1. **`tokenizer`**: A Hugging Face `PreTrainedTokenizer` instance.
2. **`model`**: A Hugging Face `PreTrainedModel` with causal LM support (e.g., Mistral, Llama, GPT-2).
3. **`prompt_text`** *(str)*: The baseline instruction/question provided to the model.
4. **`ideal_centroid`** & **`corrupt_centroid`** *(torch.Tensor)*: Dense vector centroids generated by mean-pooling the output hidden states of positive/negative exemplar texts.

### Optimization Hyper-parameters
* **`max_tokens`** *(int, default: 250)*: The maximum number of new tokens to generate.
* **`steps`** *(int, default: 8)*: The number of Adam optimizer gradient ascent steps performed per token.
* **`lr`** *(float, default: 0.5)*: The learning rate for the Adam optimizer steering hidden states.
* **`l2_weight`** *(float, default: 1.0)*: Regularization coefficient ($\lambda$) constraining drift from the initial manifold.
* **`sim_scale`** *(float, default: 100.0)*: Multiplier for similarity gradients to balance them against the L2 manifold distance.
* **`track_trajectories`** *(bool, default: True)*: Whether to log step-by-step optimization loss, similarity, and distance metrics.

## 4. Outputs & Trajectory Metrics

### Control Output (Unsteered)
Standard autoregressive text generated without gradient intervention. It serves as the baseline comparison.

### Treatment Output (Steered)
Optimized text produced by projecting the gradient-guided hidden states. It naturally integrates the structural cadence of the positive exemplars.

### Trajectory Logging
When `track_trajectories=True`, the generator yields a nested list of dictionaries containing metrics for each Adam step of every token:
```json
[
  {
    "step": 1,
    "loss": -76.43,
    "sim_good": 0.8124,
    "sim_bad": 0.1245,
    "manifold_dist": 0.0000
  },
  ...
  {
    "step": 8,
    "loss": -82.91,
    "sim_good": 0.8540,
    "sim_bad": 0.0912,
    "manifold_dist": 0.3412
  }
]
```
*A lower loss (which is a negative objective) indicates the objective function was successfully maximized.*

### DPO Dataset JSONL Output
The DPO generation export format exports preference triplets ready for Direct Preference Optimization post-training:
```json
{"prompt": "...", "chosen": "Treatment text...", "rejected": "Control text..."}
```

## 5. How to Run Locally

### Installation Requirements
Install the required packages using pip:
```bash
pip install -U bitsandbytes>=0.46.1 transformers accelerate torch pytest
```

### Running Unit Tests
A lightweight, fast-loading random GPT-2 model is configured for testing, requiring no GPU and running in under 10 seconds:
```bash
pytest test_latent_gradient_steering.py -v
```

### Programmatic Usage Example
```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM
import latent_gradient_steering as lgs

# 1. Initialize Model
model_name = "mistralai/Mistral-7B-Instruct-v0.3"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name, device_map="auto")

# 2. Extract Centroids
positives = ["Nuclear detonations created a globally synchronous radiocarbon spike..."]
negatives = ["Alien structures vanished leaving zero rocks or evidence..."]

ideal_centroid = lgs.get_centroid(positives, tokenizer, model)
corrupt_centroid = lgs.get_centroid(negatives, tokenizer, model)

# 3. Generate Steered Output
prompt = "Evaluate physical evidence of ancient civilizations."
steered_text, trajectories = lgs.generate_treatment(
    prompt_text=prompt,
    tokenizer=tokenizer,
    model=model,
    ideal_centroid=ideal_centroid,
    corrupt_centroid=corrupt_centroid,
    max_tokens=150
)

print(steered_text)
```
